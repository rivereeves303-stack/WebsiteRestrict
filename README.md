# 留白 · WebsiteRestrict

给容易分心的网站设置边界。一个中文 Manifest V3 浏览器扩展，支持每日使用额度、每周禁用时段和日期限制，无需账号，数据保存在本机。

## 功能

| 限制方式 | 示例 |
| --- | --- |
| 每日额度 | 每天最多使用视频网站 30 分钟 |
| 每周时段 | 周一至周五 09:00–18:00 禁用，支持跨午夜 |
| 日期范围 | 备考期间禁用，包含开始和结束当天 |
| 始终禁用 | 开启规则期间一直禁止访问 |

- 前台停留即计时，首页、不播放视频、没有鼠标键盘操作时也会累计。切换标签页、其他应用或锁屏后暂停。
- 网站右下角只显示剩余时间，到时进入限制提醒页，显示预计恢复时间。
- 输入网站域名或完整网址，限制覆盖网站及其子域名。多条规则重叠时，任意一条生效就会拦截。
- 修改保护支持 4 位数字按钮密码，或禁止复制粘贴的文字挑战；每次验证任选一种。

## 本地安装

1. 下载或克隆本仓库；下载 ZIP 时先解压。
2. 打开浏览器的扩展管理页：Chrome 为 `chrome://extensions`，Edge 为 `edge://extensions`，Vivaldi 为 `vivaldi://extensions`。
3. 开启「开发者模式」，选择「加载已解压的扩展程序」。
4. 选择包含 `manifest.json` 的项目根目录。
5. 打开「留白」→「管理网站与规则」→「添加网站规则」。

可先将 `example.com` 设为「始终禁用」，访问它确认拦截是否生效。没有工具栏入口时，在扩展的「详细信息」中打开「扩展程序选项」。

修改或更新源文件后，在扩展管理页点击「重新加载」，重新打开设置页，并刷新受限网站。覆盖原安装目录即可保留原有规则；更换加载目录可能改变扩展 ID。

## 使用说明

### 每日用量和倒计时

每日额度支持 1–1440 分钟，按本机时间在零点重置。只统计浏览器前台窗口的活动标签页，不依赖声音或视频播放。多条额度规则分别累计，首页总用量不重复计算。

正常网页右下角显示可用时间；额度与定时限制重叠时，显示更早到期的时间。暂停限制、没有匹配规则或日期限制已结束时隐藏。提醒页综合重叠规则计算可恢复访问的时间；始终禁用或连续覆盖时显示「持续限制中」。

后台通常每 30 秒更新限制，网页计时每 10 秒校准。系统休眠和浏览器调度可能带来延迟；每次检查最多补计 60 秒，避免将长时间休眠算作浏览。

### 修改保护

在规则列表下方打开「设置保护」，勾选「开启修改与关闭保护」。需要密码时，点击密码框，再用数字按钮输入并确认固定 4 位密码，支持清空、退格和开头的零；已有密码留空可保留。

| 操作 | 是否需要验证 |
| --- | --- |
| 添加新规则、开启单条规则、开启总开关 | 不需要 |
| 修改或删除已有规则、暂停单条规则、关闭总开关 | 需要 |
| 修改保护设置、插件内申请卸载 | 需要 |

设置密码后，每次可任选密码或文字挑战，通过一种即可。文字挑战禁用复制、粘贴和拖放，支持中文输入法。密码输错可立即重试，没有次数限制或冷却；一次验证仅适用于对应操作，5 分钟有效。

旧版密码不是 4 位数字时，可通过文字挑战将它改为新密码。规则暂停不会重置今日用量。

## 兼容性与边界

采用 Chromium Manifest V3，最低 Chromium 版本为 120。已在 Edge 中执行自动化浏览器验证；Chrome、Vivaldi 可本地加载，具体版本仍建议自行验收。未提供 Firefox 版本。

这是个人自律工具。普通扩展无法阻止浏览器自身的停用、移除或修改系统时间，也无法限制其他浏览器。插件内验证不等于浏览器级防卸载。无痕模式需要单独授权，不保证与普通窗口独立计时。

仅支持 HTTP / HTTPS 网站，不支持按网址路径分别限制。浏览器内部页和扩展商店等禁止脚本注入的页面不支持网页计时条。解除限制后需重新访问原网站，不自动恢复之前的页面。

## 开发

Node.js 22+，无需安装依赖：

```sh
npm run check
npm test
npm run package
```

安装包生成在 `dist/website-restrict-v<版本>.zip`，只包含扩展运行文件。历史压缩包、浏览器配置、私钥及本地环境文件均不提交到 Git。

详细说明见 [开发与验证](docs/DEVELOPMENT.md)，权限与数据处理见 [隐私说明](docs/PRIVACY.md)。
