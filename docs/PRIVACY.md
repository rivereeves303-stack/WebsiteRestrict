# 隐私说明

留白在本机处理网站限制规则和使用时长，不向开发者服务器上传数据，不接入广告或第三方统计服务。

## 本地数据

- 限制规则、域名、今日用量与保护设置保存在浏览器扩展的本地存储中。
- 后台计时会暂存当前计时标签页的地址、标签页标识和计时起点，用于累计前台停留时间，不建立完整的浏览历史记录。
- 密码使用随机盐和 PBKDF2-SHA256 保存散列，不保存明文。
- 待验证操作和随机文字挑战暂存在浏览器会话存储中。网页内的计时条只接收当前网站的计时状态，不接收保护密码或其他网站的规则。

## 权限用途

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存规则、今日用量和计时检查点 |
| `tabs` | 判断前台网站，并处理已经打开的受限标签页 |
| HTTP / HTTPS 网站访问 | 匹配设置的域名、展示计时条和限制导航 |
| `alarms` | 定期更新规则与用量 |
| `idle` | 判断锁屏；普通无操作空闲不会暂停计时 |
| `declarativeNetRequest` | 将受限网站导航到扩展内的提醒页 |

用户可以编辑或删除规则。删除规则会移除该规则的今日用量，当日首页总用量保留。卸载扩展会由浏览器移除对应的扩展数据；项目不提供云端备份。

此文件描述当前项目的数据处理行为，供使用者和开发者查阅。提交扩展商店时，发布者还需要提供联系方式、发布日期与可访问的政策链接。
